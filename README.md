# Psicología y Salud · la bibliografía en scrollytelling

Material de estudio del curso **Psicología y Salud** (Ciclo de Formación Integral) — Facultad de Psicología, Universidad de la República (Udelar), Uruguay, 2026.

> **No es material oficial de la cátedra.** Es una guía de estudio hecha por un estudiante: puede tener errores y no reemplaza la lectura de los textos ni las clases. Sugerencias y correcciones: [formulario anónimo](https://docs.google.com/forms/d/e/1FAIpQLSdlGHKe1mQkOpu08XCI74bMj4xcfwd6cuSYiLJaeKdtcb-ZtQ/viewform?usp=publish-editor).

Recorre la bibliografía básica de las diez unidades del programa, texto por texto: contexto y problema de cada texto, una primera lectura, diagramas que se arman con el scroll, recuadros de caso, anticipación y recontextualización, trampas de examen, tres preguntas de desarrollo con respuesta modelo y veinte verdadero o falso con justificación por texto.

**Ver online:** https://pasquinell.github.io/psico-y-salud/

## Estructura

- `index.html`: el material completo (un solo archivo con HTML, CSS y JS; sin build ni dependencias salvo Google Fonts).
- `img/hygieia.jpg`: Gustav Klimt, *Hygieia*, detalle de *La Medicina* (1900-1907). Dominio público, vía [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Klimt_Hygieia.jpg).
- `.nojekyll`: hace que GitHub Pages sirva los archivos tal cual.
- `doc/README.md`: documentación para seguir editando el sitio. `doc/tools/`: scripts de verificación.

Las citas marcadas ≈ son fieles al sentido pero no están verificadas como literales: no las entrecomilles en un examen sin cotejarlas con el texto.
